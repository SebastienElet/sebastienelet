# Hi, I’m Sébastien 👋

I’m a TypeScript developer based in Amiens, France. I like command-line interfaces,
Neovim, and relational databases. My current focus is on coding-agent tooling,
software quality, and building a useful knowledge base.

## What I’m interested in

- **AI-assisted software development** — making coding agents useful in everyday
  work through shared instructions, reusable skills, project memory, and code review.
- **Developer tooling and automation** — small CLIs, reproducible environments,
  and fewer manual steps between an idea and a verified change.
- **Software quality** — simple designs, explicit domain models, strict types,
  and tests that exercise real behavior. I value code that stays easy to understand
  and maintain.
- **Knowledge management** — organizing and connecting knowledge in Obsidian,
  with an interest in making that context useful to both people and agents.
- **Relational databases** — PostgreSQL, data modeling, and keeping business
  invariants explicit.

## What I’m working on

My main public work currently lives in
[dotfiles](https://github.com/SebastienElet/dotfiles): my macOS development
environment and the tooling around it. Recent work focuses on shared project
memory for Codex and Claude Code, agent configuration diagnostics, and keeping
instructions and skills consistent across tools.

I’m also spending a lot of time on my **Obsidian knowledge base**: organizing what
I learn and working on how to find and reuse it in day-to-day work.

Another area I’m exploring is bringing information from everyday applications into agent
workflows. [mst-cli](https://github.com/SebastienElet/mst-cli) is an early project
for accessing Microsoft Teams through its web client and exporting conversations
to Markdown. Parts of the workflow are still being specified.
